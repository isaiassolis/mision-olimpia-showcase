# Política de publicación del portafolio

Este repositorio es una demostración documental del proyecto, no una distribución del sistema.

## No publicar

- Código fuente ni historial Git del repositorio de desarrollo.
- Nombres, identificadores, respuestas o resultados de estudiantes reales.
- Exportaciones JSON con sesiones reales.
- Cuadernillos, escaneos, bancos de preguntas o imágenes de terceros sin permiso.
- Rutas locales, archivos temporales, cachés o datos del navegador.

## Capturas permitidas

Solo capturas reales de la aplicación, revisadas manualmente y con datos ficticios. Deben ocultarse nombres, calificaciones reales, identificadores, notificaciones y rutas locales visibles.

## Aclaración de propiedad intelectual

La documentación del portafolio no implica que el código fuente esté publicado o licenciado. Cualquier futura publicación de software requerirá una decisión explícita sobre licencia, dependencias y derechos de contenido.
